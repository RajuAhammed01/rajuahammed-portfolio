# rajuahammed-portfolio

> Personal Portfolio of **Raju Ahammed** — Aspiring AI/ML Engineer.
> Built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

## 🚀 Overview & Positioning
A modern, recruiter-friendly personal portfolio showcasing machine learning systems, deep learning projects, predictive modeling, data analysis, and academic foundations.

### 🌟 Key Highlights
- **Modern Responsive Navbar**: Circular `RA` branding, 7 section links, smooth scroll, and mobile drawer.
- **Light/Dark Mode Theme Toggle**: Seamless theme switching with system detection and persistence.
- **Featured Projects**: End-to-end ML projects (Car Price Prediction, Disease Prediction System, Exam Result Predictor, JobSnap recommendation engine).
- **Technical Skills**: Grouped by Programming Languages, ML & Data Science, Backend, and Visualization tools.
- **Research & Continuous Learning**: Exploring deep learning, computer vision, hyperparameter optimization, and data quality.
- **Certifications & Achievements**: Verified Frontend Masters course completions (TensorFlow 2.0 & Keras, SQL Fundamentals, Intermediate Python) and engineering milestones.
- **Academic Foundation**: Computer Science and Engineering at University of Liberal Arts Bangladesh (ULAB).
- **Interactive Contact**: Form with direct pre-addressed mailto integration and clipboard copy.

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, Vanilla CSS Design System Tokens
- **Icons & Visuals**: Custom SVGs, glassmorphism, responsive data motifs

## 💻 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.

## 📦 Production Build

```bash
npm run build
```
