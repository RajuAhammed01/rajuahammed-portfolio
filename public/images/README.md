# Profile Photo Instructions

Place your portrait photo in this directory with the exact filename:
`profile.jpg`

### Recommended Image Specs:
- **Aspect Ratio**: 4:5 (e.g., 800x1000px or 1200x1500px)
- **Format**: JPG or PNG
- **Composition**: Professional headshot / portrait
- **File path**: `/public/images/profile.jpg`

The portfolio will automatically detect and render your photo in the Hero section.
If this file is not found, an elegant placeholder is automatically displayed so the layout is never broken.
